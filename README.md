# Knowing When to Interrupt: Threshold, a Proactive Agentic Tutor for CS1 Debugging

CS567 (Agentic-AI Human-Centered Computing) project by Samuel Abdullahi Abeeb, Colorado State University.

Threshold is a tutor for novice Python programmers that detects when a student keeps failing on the same runtime error and opens a Socratic dialogue on its own, without ever giving solution code.
